# Privacy Policy — VET

This holds one page: the privacy policy for VET, a football simulation app. It is served as
plain text with no theme, no script, no stylesheet and no external asset of any kind, so that
reading it collects nothing about you - which is the same promise the policy itself makes.

Questions about the policy, or a request to remove an identifier from the full-access list, go
to stuckonpandora@gmail.com.

The text is written and reviewed elsewhere and copied here by hand. The page never edits itself,
and the date at the top of it is the day it was first published here.
